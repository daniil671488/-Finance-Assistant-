# Финансовый помощник (Finance Assistant)

## Проблема
Пользователи теряют контроль над повседневными тратами, не замечают мелких расходов и в конце месяца не понимают, куда ушла большая часть денег.

## Пользователь
Студент или офисный работник с фиксированным доходом, который хочет контролировать личный бюджет.

## Результат
Вводит свои расходы и получает наглядную сводку: сколько всего потрачено, распределение по категориям и какая категория съедает больше всего бюджета.

## MVP
- Добавить новый расход с указанием суммы, категории и даты.
- Показать список всех расходов за выбранный период.
- Показать статистику — сумму и долю (в %) расходов по каждой категории.
- Показать самую затратную категорию (на что уходит больше всего денег).
- Дополнительно: Экспортировать историю расходов в файл CSV.

## Ограничения первой версии
Не подключается к банковским API, не поддерживает мультивалютность (только одна валюта), не имеет графического интерфейса (GUI) и не работает с облачной синхронизацией.

## Статус
Проектирование и начальная реализация.

## Запуск
Инструкция будет уточняться по мере появления исполняемой версии.
