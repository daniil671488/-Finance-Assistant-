# Контракты функций

## add_expense

Файл: app/logic.py

Назначение:
Проверить корректность введенных данных о расходе и вернуть нормализованный объект расхода для последующего сохранения.

Вход:
amount: float — сумма расхода

category: str — название категории

date: str — дата в формате YYYY-MM-DD

description: str — описание (может быть пустым)

Выход:
dict (словарь), содержащий проверенные данные: {"amount": 150.0, "category": "Еда", "date": "2026-11-23", "description": "Обед"}.

Ошибки:
ValueError при amount <= 0, при неверном формате date (или невозможной дате, например, 31 февраля) или если category пустая.

Побочные эффекты:
Отсутствуют (функция только валидирует данные, сохранение происходит в другом месте).

Acceptance Criteria:
1. Корректные данные (сумма 500.0, дата "2026-12-01", категория "Транспорт") принимаются.
2. Отрицательная сумма отклоняется с ошибкой.
3. Неверная дата (например, "2026-02-29" или "23.11.2026") отклоняется.
4. Пустая строка в категории отклоняется.
