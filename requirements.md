# Требования

## Функциональные требования
FR-1. Пользователь может добавить расход, указав сумму, категорию (например, Еда, Транспорт, Развлечения, Жилье), дату и краткое описание.

FR-2. Пользователь может получить список всех расходов за указанный месяц.

FR-3. Пользователь может запросить статистику, которая выводит сумму и процент от общего бюджета для каждой категории.

FR-4. Система должна автоматически определять и выводить категорию с максимальной суммой трат.

FR-5. При некорректных данных (отрицательная сумма, несуществующая дата, пустая категория) система должна вывести понятное сообщение об ошибке и не сохранять запись.

## Нефункциональные требования
NFR-1. Проект запускается по инструкции README в чистом окружении Python 3.10+ без сложных внешних зависимостей.

NFR-2. Данные сохраняются локально в файл data.json. Секреты и личные данные не хранятся в репозитории и не отправляются в сеть.
