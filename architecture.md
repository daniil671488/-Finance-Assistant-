# Архитектура

## Точка запуска
main.py

## Компоненты
- app/interface.py — взаимодействие с пользователем.
- app/logic.py — бизнес-правила и проверяемая логика.
- app/storage.py — сохранение данных и/или внешние интеграции.
- tests/ — автоматические тесты.

## Правила зависимостей
1. Интерфейс вызывает бизнес-логику.
2. Бизнес-логика не должна напрямую читать input() или печатать пользовательский интерфейс.
3. Работа с файлами, сетью или API отделяется от чистых правил предметной области.

## Дополнительные замечания
app/models.py — модуль для описания структуры объекта «Расход» (dataclass). Интерфейс не работает с файлами напрямую, только через логику и хранилище.
